### 引擎模式

| 指令 | 行为 |
|---------|----------|
| "引擎设为模板优先"（默认） | 先搜模板库；匹配不到自动转 LLM |
| "引擎设为纯LLM" | 跳过模板库；宿主 AI 直接优化 |
| "引擎设为仅模板" | 只查模板库；匹配不到告知用户 |

## 📊 质量评估

说"评估"（或任何等价说法）触发前后对比。5 个维度各打 1-10 分：

| 维度 | 衡量什么 |
|-----------|-----------------|
| goalClarity | 目标是否清晰具体 |
| instructionCompleteness | 指令是否完整无歧义 |
| structuralExecutability | 结构能否逐步执行 |
| ambiguityControl | 模糊表述是否已消除 |
| robustness | 不同输入下是否稳定 |

输出：前后评分对比 + 总提升 + 改进亮点 + 剩余差距。

## 🧠 四种优化模式

| 模式 | 何时用 | 做什么 |
|------|------|-------------|
| **通用**（默认） | 大多数场景 | 结构化 Role/Profile/Skills/Rules/Workflows 输出 |
| **分析式** | 复杂场景 | 8 维度深度分析，每维度 5 个要点 |
| **迭代式** | 说"继续优化" | 把新需求融入已有提示词 |
| **用户查询精炼** | 优化用户查询 | 补齐清晰度、范围、参数、输出格式 |

## 🔧 完整工作流

```
1. 开启 → 检测平台能力 → 加载默认值
   ├─ 文件系统可用 → 模板引擎就绪
   └─ 文件系统不可用 → 自动切换 LLM-only 模式
2. 用户提交提示词
3. 解析意图（目标、领域、角色、约束、复杂度）
4. 引擎路由：
   ├─ 模板优先：搜索 → 匹配 → CRAFT 输出 / 无匹配 → LLM 兜底
   ├─ 纯LLM：元提示直接生成
   └─ 仅模板：搜索 → 匹配 → 输出 / 无匹配 → 告知用户
5. 质量增强（精确指令 + 约束 + 示例）
6. 确认交付
7. 可选：评估 / 迭代 / 微调
```

## 🛡️ 特性

- **零 API 成本** —— 宿主 AI 直接优化，无额外开销
