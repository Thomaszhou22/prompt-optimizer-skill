# Prompt Optimizer Skill

> 🚀 Transform vague natural language into precise, high-quality prompts using a curated library of 2,200+ proven templates from 7 GitHub repositories.

## What It Does

Users speak naturally → the skill matches their intent against 2,200+ professional prompt templates → outputs a structured, optimized prompt they can use with ANY AI model.

## Features

- **2,200+ Prompt Templates** from 7 major repositories
- **Two Modes**: Lite (1.9MB, fast) and Full (8.5MB, complete)
- **14 Categories**: 编程开发, 写作创作, 教育学习, 商业职场, 生活健康, 技术工具, 语言翻译, 艺术娱乐, 顾问咨询, 创意生成, 数据分析, 科学研究, 法律金融, 其他
- **CRAFT Framework**: Every optimized prompt includes Context, Role, Action, Format, Target Audience
- **Bilingual**: Chinese and English support
- **Model-Agnostic**: Works with ChatGPT, Claude, GLM, Gemini, or any AI
- **Smart Toggle**: On/Off switch with version auto-suggestion

## How to Use

### As an OpenClaw Skill
1. Copy this folder to your `skills/` directory
2. Say "开启简易版提示词优化" (lite) or "开启完整版提示词优化" (full)
3. Say any task → get an optimized prompt → confirm or tweak → use it

### Standalone
Read `SKILL.md` and `references/prompt_library_*.json` to integrate into your own workflow.
